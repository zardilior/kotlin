# Raw FIR Creation

This module is the first stage in the [FIR](../ReadMe.md) compilation pipeline. Its core responsibility is to convert the source code representation—typically a [PSI](../../psi/ReadMe.md) tree—into an initial, "raw" FIR tree. At this stage, the FIR tree is purely syntactic; it has not undergone semantic analysis, so types are unresolved and references are not yet bound.

## Key Concepts

- **Syntactic Transformation:** The process is a direct transformation from the syntax tree to an intermediate representation. The resulting FIR tree closely mirrors the structure of the source code but is in a format that is optimized for the subsequent semantic analysis phases.
- **Unresolved State:** It is critical to understand that the FIR elements created in this stage are "raw." This means that `FirTypeRef` elements have not been resolved to actual types, and `FirResolvedIdentifier` elements do not yet point to their declarations. The `resolve` phase is responsible for filling in this semantic information.

## Sub-modules

- **`/psi2fir`:** This is the primary converter. It contains the logic to traverse a PSI tree, which is the standard representation generated by the parser, and build a corresponding raw FIR tree. It is used in most standard compilation scenarios, including in the IntelliJ IDEA plugin.
- **`/light-tree2fir`:** This module provides an alternative converter that operates on a "light tree," which is a more memory-efficient, string-based representation of the source code. This is often used in performance-critical scenarios where building a full PSI tree would be too resource-intensive.
- **`/raw-fir.common`:** As the name suggests, this module contains common logic, data structures, and utilities that are shared between the `psi2fir` and `light-tree2fir` converters.
